emrs-dirdiff: three ways to show a directory comparison

Each box is the same comparison of ~/src/app-1.4 with ~/src/app-1.5 as an Emacs buffer. Identical entries are hidden by default in all three. Pick one, or name the parts you would combine.

Merged tree with a status column

*dirdiff: app-1.4 ↔ app-1.5* content · gitignore on · 867 files in 0.4 s
For: fits a half-width window, full names stay readable, room for sizes and line counts, easy to mark and filter.
Against: the side is a letter and a colour, not a position; unlike Beyond Compare.

Shared by all three: results while it runs

The buffer opens at once and fills as the module reports differences. Leaving the buffer or C-g cancels the comparison.

Shared by all three: one menu for every key

? opens a menu that lists the commands and shows the current settings, so nothing has to be remembered or set in the init file.

Open                     Move                 Show
 RET diff this file       n p next, previous    s same files      off
 e   ediff                N P next, prev. dir   i ignored files   off
 o   visit A   O visit B  TAB fold directory    / filter by name
 d   dired here           ^   parent            f only changed / A / B

Act (on the marked entries, or the one at point)      Compare by
 m u mark, unmark         > copy A → B          c content         on
 U   unmark all           < copy B → A          t size and time
 D   delete               w copy path           W ignore whitespace off
                                                I respect .gitignore on
 g   compare again        x swap A and B        q quit
